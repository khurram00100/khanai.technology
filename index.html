TradingX

An AI agent that ingests real-time market data and generates directional predictions for currencies, gold, and Bitcoin — approximately 75% accuracy. ML models and automated data pipelines.

Core function

What TradingX does

Continuously ingests live market data, processes through trained ML models, and outputs directional predictions (up/down/hold). Decision-support tool — not financial advice.

Real-time data pipeline
Coverage

Supported assets

  • Major forex pairs — USD, EUR, GBP, JPY and more
  • Gold (XAU/USD) — commodity price prediction
  • Bitcoin (BTC/USD) — crypto directional forecasting
  • Expandable via additional data source integration
Performance

~75% accuracy

Approximately 75% directional accuracy under standard market conditions. This is directional correctness (up/down), not price-level precision. Results vary by volatility.

~75% directional accuracy
Architecture

How it works

  • Connects to live market data APIs for OHLCV data
  • Preprocesses and normalizes via automated pipelines
  • Runs trained ML classifiers for trend prediction
  • Outputs directional signal with confidence score
  • Optional integration with trading platforms

1. Information We Collect

WinPilot AI collects only the minimum information required for the application to function.

Account Information

When you create an account:

  • Email address
  • Account name
  • Subscription plan information
  • Login timestamps

Used only for authentication and subscription management.

2. Chat Data

Chat messages and conversation history may be stored to improve user experience.

Local Storage

Chat history is stored locally on your device in encrypted format.

Cloud Storage (Optional)

If cloud synchronization is enabled, chat data may be stored securely using Supabase cloud database infrastructure. All transmission is encrypted using HTTPS.

3. AI Services

WinPilot AI may connect to third-party AI providers to generate responses:

  • Google Gemini (Google LLC)
  • OpenAI ChatGPT (OpenAI, L.L.C.)
  • Anthropic Claude (Anthropic PBC)

When using these models, your message may be sent to the selected provider for processing. These providers operate under their own privacy policies.

4. Voice Input and Microphone Usage

  • Voice recognition is processed locally using offline models such as Vosk.
  • Audio is not stored permanently by the application.
  • Voice data is not transmitted to external servers by WinPilot AI itself.

5. Payment Information (Razorpay)

Payments are processed securely using Razorpay. WinPilot AI does not store card numbers, CVV codes, or bank credentials. Only Razorpay payment reference IDs are stored to confirm successful transactions.

6. Device Permissions

  • Microphone — voice command functionality
  • File System Access — saving settings, chat history, and user data locally
  • Internet Access — AI model communication, cloud sync, and updates

7. Data Security

  • AES encryption for locally stored chat data
  • HTTPS encrypted communication for all transmissions
  • Secure Supabase cloud database infrastructure
  • No storage of sensitive financial information

8. Data Sharing

WinPilot AI does not sell, rent, or share your personal data with third parties for advertising. Data is shared only with AI service providers, Razorpay for payment processing, and Supabase for cloud infrastructure — as required for operation.

9. User Rights

You have the right to access your stored data, request deletion of your data, and delete your account. Deleting your account may permanently remove all associated cloud data.

10. Children's Privacy

WinPilot AI is not intended for children under 13. If we become aware that data has been collected from a child under 13 without parental consent, the account will be removed immediately.

11. Changes to This Policy

We may update this Privacy Policy from time to time. Updates will be published on this page with a new effective date. Continued use of the application constitutes acceptance of the updated policy.
